11月走量前20参考（批发价约 元/斤）

  1. 蜜橘（湖南/临海涌泉）— 勾庄日销200+吨的绝对主力；湖南货约1.3-2元/斤，涌泉精品5-7元/斤。10月底外地货逐步下市、本地精品接棒，价格易涨难跌
  2. 红富士苹果（陕西洛川/山东烟台）— 晚熟富士集中上市期，市场价约3.5-4.9元/斤；你这个价进的陕西货有空间
  3. 阿克苏冰糖心（新疆）— 霜降后正宗货上市，产地约3.2-3.5元/斤，做尝鲜款
  4. 蜜柚（广西/福建）— 约1.4-2.6元/斤，大件耐放走量
  5. 香蕉 — 全国均价约2.3元/斤；佳农品牌货按箱拿的要留意零售定价
  6. 皇冠梨 / 秋月梨（河北）— 皇冠约3-3.9元/斤、秋月3.9-7.5元/斤
  7. 砂糖橘（广西/云南）— 刚上市量少价高约2.3-4.5元/斤，11月中下旬放量降价，先少量试
  8. 猕猴桃（浙江/陕西/四川）— 约3.2-6.5元/斤
  9. 柿子（云南/广西/湖北）— 约2-4.5元/斤，耐放损耗低
  10. 冬枣（陕西/甘肃）— 约4-7.8元/斤
  11. 脐橙（江西）— 11月新果上市，约2.3-3.5元/斤，可以关注
  12. 果冻橙·爱媛（江西/福建）— 约2-3.1元/斤，网红款零售溢价好
  13. 石榴（四川/贵州）— 约3.5-4.8元/斤
  14. 哈密瓜（新疆/海南）— 约2.4-6.3元/斤，尾季少进
  15. 西瓜 — 全国均价约2元/斤，尾季收尾货，不建议再压
  16. 火龙果（广西/海南）— 约2.1-4.5元/斤
  17. 阳光玫瑰 / 巨峰葡萄 — 约6.3-12 / 4.5-6元/斤，尾季转淡少进

备份与恢复

数据存在这台设备的浏览器里。换手机、清缓存之前，先导出一份。

本机自动备份 · 防丢保险

每次改动满 5 分钟自动在本机存一份快照（最多 12 份）。数据被同步覆盖、误删、清错时，在这里一键找回——恢复是按条合并，不会覆盖现有数据。

云同步 · 电脑手机实时同步

数据同步到你的 GitHub 私密 Gist（只有持 token 的人能读）。改动约 1-2 秒自动上传，每 45 秒和切回页面时自动拉取，断网存本机、恢复后补传。

Token 获取（一次性，两台设备用同一个）：打开 github.com/settings/tokens/new（已预选 gist 权限，其他不用勾）→ 点 Generate token → 复制 ghp_ 开头字符串粘到上面。Token 只存在本设备浏览器里，不进代码不上传。第二台设备选「连接已有云端」即可找到同一份数据。
